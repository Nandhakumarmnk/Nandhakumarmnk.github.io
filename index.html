About

Engineering that holds up in production

I'm a Senior .NET Full-Stack Developer and Technical Lead with 5 years of experience at Spark IT Tech, Tiruppur, building enterprise web applications end to end — React.js and TypeScript on the front, .NET 8 / ASP.NET Core and C# behind it, and SQL Server underneath.

On the Vendor Portal I built the vendor-facing UI in React.js with TypeScript — a reusable component set of forms, grids, modals, and validation shared across registration, onboarding, and approval screens — and integrated it with RESTful .NET APIs secured by JWT and role-based routing, so vendors, buyers, and approvers each see only their permitted screens. On the established MVC modules I still ship server-rendered screens with JavaScript, jQuery, AJAX, and Bootstrap.

My work sits where correctness matters most. I led a four-phase security remediation programme that resolved 500+ security issues/findings — XSS, SQL Injection, CSRF, and unsafe file upload paths — across a system that could not be taken offline. I built the SAP Business One synchronisation services from scratch, replacing manual cross-team reconciliation with near real-time data exchange.

As Technical Lead I own task breakdown, estimation, design discussions, and code reviews, and mentor developers on .NET, React, and secure coding practice. I tune T-SQL workloads down to sub-second under peak load and set the standards the team reviews against.

I also own releases end to end: IIS site hosting and server configuration, SSL binding, EF Core migrations with matching rollback scripts, and production-to-UAT refreshes using data masking and validation of sensitive fields. Deployments run in scheduled off-peak windows with pre-tested rollback and post-deployment validation, delivering without downtime while meeting agreed SLA commitments, followed by deployment support for QA, UAT, and business teams until every module is signed off.

Outside the day job I take products all the way to release on my own — an offline-first ASP.NET Core 8 order platform with a Firestore sync relay for a fireworks business, a Flutter household finance app running on Android, iOS, and Web from one codebase, and an offline image compressor shipped as both a PWA and a signed Android APK.

I was an early adopter of AI-assisted development on my team, introducing Claude Code and ChatGPT into our feature and code review workflow. Currently deepening Azure, Docker, and microservices.
